# 2048 Terminal Game (Java)

Implementasi game puzzle angka **2048** yang berjalan langsung di terminal menggunakan **Java**. Geser dan gabungkan ubin bernomor sama untuk mencapai **2048** (atau skor setinggi mungkin) sebelum papan penuh.

## ✨ Fitur
- **Berbasis Terminal (CLI):** Ringan dan dapat dijalankan langsung lewat *command line*.
- **Logika Permainan Lengkap:** Pergeseran ubin, penggabungan nilai yang sama (sekali merge per langkah), *spawn* ubin acak (`2` atau `4`), serta deteksi menang & *game over*.
- **Pelacakan Skor:** Menampilkan skor saat ini (dan *best score* jika diaktifkan).
- **Struktur Berorientasi Objek (OOP):** Pemisahan logika papan, alur permainan, dan input pengguna.
